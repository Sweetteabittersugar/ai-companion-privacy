AI 伴侣隐私政策

生效日期：2026-06-30

AI 伴侣是本地优先的开源 AI 陪伴应用。我们不运营业务服务器，不提供账号系统，也不采集用户数据。用户需要自行配置 Xiaomi MiMo 或 DeepSeek API Key，应用会从设备直接请求用户选择的 AI 服务。

我们不收集的数据

AI 伴侣不收集、不上传、不分析以下数据：

  • 聊天记录
  • 长期记忆和语义事实
  • 角色设定、角色库和人格配置
  • 出生日期、年龄验证状态和个人资料
  • API Key
  • 设备通讯录、相册、定位、麦克风或摄像头数据

本地保存的数据

以下数据保存在用户设备本地：

  • 对话、消息和角色信息
  • 记忆、事实和人格设置
  • 年龄验证状态
  • 通知提醒开关、主题偏好等设置

API Key 使用系统安全存储保存，例如 iOS Keychain 或 Android Keystore。清除所有数据时，应用会同时清除本地数据库、配置和安全存储中的 API Key。

Android 版本会关闭系统自动备份，避免聊天、记忆、角色和设置被操作系统自动同步到云端备份。用户主动使用“导出数据”时，应用只会在本机生成 ZIP 文件，并交由系统分享面板处理。

AI 服务请求

当用户发送消息、生成角色或触发记忆整理时，应用会把完成该功能所需的上下文直接发送到用户选择的 AI provider：

  • Xiaomi MiMo
  • DeepSeek

这些请求不经过 AI 伴侣项目服务器。对应 provider 对数据的处理方式由其服务条款和隐私政策约束。用户应自行确认所选 provider 是否符合自己的隐私要求。

联机功能

多人群聊和游戏功能需要用户配置 WebSocket 联机服务地址。启用后，房间消息会发送到用户选择的联机服务端，用于实时同步多人状态。单人 AI 陪伴功能不需要业务服务器。

iOS 版本仅在用户配置局域网 WebSocket 地址时使用本地网络访问；Android 版本仅声明通知、震动、网络状态和生物识别等运行所需权限，不申请通讯录、相册、定位、麦克风或摄像头权限。

年龄验证

AI 伴侣仅限 18 岁以上用户使用。出生日期只在设备本地用于计算年龄，不上传、不保存完整生日。

数据导出和删除

用户可以在设置中导出本地数据 ZIP，也可以清除全部本地数据。清除操作会删除：

  • 对话和消息
  • 记忆和事实
  • 角色、人设和设置
  • API Key
  • 年龄验证状态
  • 本地 AI 回复反馈记录

用户长按 AI 回复并选择“标记不适当”时，应用只会在本机保存一条反馈记录，用于用户自行审查或导出。该反馈不会自动上传到 AI 伴侣项目服务器；导出数据时会包含 safety-feedback.json。

第三方 SDK 和网络出口

应用使用 Expo / React Native 生态组件提供本地存储、通知、分享和系统能力。网络出口通过静态审计限制为：

  • 已声明的 AI provider 域名
  • 用户配置的联机 WebSocket 地址
  • 用户主动点击打开的 provider 文档/注册链接

联系和开源审计

AI 伴侣是开源项目。用户可以审计源码、构建产物和网络出口，确认数据处理行为是否符合上述说明。
