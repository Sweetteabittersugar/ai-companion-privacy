AI Companion Support

If you need help with AI Companion, use the support checklist below.

Before You Contact Support

  • Confirm you are using the current app version.
  • Confirm your Xiaomi MiMo or DeepSeek API key is active.
  • Confirm the selected model ID matches the provider account.
  • If multiplayer is enabled, confirm the WebSocket URL uses wss:// for public deployments.

Common Issues

Provider Validation Fails

Open Settings, verify the provider is Xiaomi MiMo or DeepSeek, then re-enter the API key. AI Companion does not operate an account system and does not store provider keys on a project server.

Clear Local Data

Open Settings and use Clear all data. This removes local conversations, memories, personas, settings, age-gate state, local AI reply feedback, and saved provider keys from secure storage.

Export Data

Use Export data in Settings to create a local ZIP file. The export can include safety-feedback.json when you have marked local AI replies as inappropriate.

Privacy And Data Handling

Read the privacy policy at ../privacy/. AI requests go directly from your device to the provider you configured. AI Companion does not collect chat history, memories, personas, birth date, or API keys on a project server.

Contact

For release support, use the store review contact channel or the project issue tracker configured by the release owner. Include the app version, platform, provider name, model ID, and a short description of the problem. Do not include API keys.
